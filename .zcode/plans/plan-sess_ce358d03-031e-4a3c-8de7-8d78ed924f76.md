# 方式 B 部署计划 — TrueNAS UI Custom App

## 环境信息
- TrueNAS: 192.168.1.3 (25.10 Goldeye)
- 存储池: a
- Docker Hub: oceaneit/sso
- PostgreSQL/Redis: 192.168.1.3 (密码: sso)

## 步骤

### Step 1: 生成安全密钥（我来执行）
- `MFA_RECOVERY_HMAC_KEY` = `openssl rand -hex 32`
- `METRICS_PASSWORD` = 随机 16 位字符串

### Step 2: 构建并推送镜像（我来执行）
```bash
docker build -f docker/Dockerfile -t oceaneit/sso:latest .
docker push oceaneit/sso:latest
```

### Step 3: TrueNAS 上准备（用户操作）
1. 通过 UI: **Storage** → **Pools** → 池 `a` → **Add Dataset** → 名称 `sso-keys`
2. 通过 Web Shell 或 SSH 生成 RSA 密钥

### Step 4: TrueNAS UI 安装 Custom App（用户操作）
- **Apps** → **Custom App** → **Install**
- 上传 docker-compose.yml（我会提供完整内容）
- 环境变量包含全部配置（DB/REDIS/JWT/MFA/CORS等）
- 数据卷挂载 `/mnt/a/sso-keys` → `/app/keys`

### Step 5: 运行数据库迁移（我来执行）
```bash
DATABASE_URL="postgres://sso:sso@192.168.1.3:5432/sso?sslmode=disable" make migrate-up
```

### Step 6: 验证
```bash
curl http://192.168.1.3:9090/health
```

## 关键配置
- PostgreSQL: `192.168.1.3:5432` / user: `sso` / password: `sso`
- Redis: `192.168.1.3:6379`
- 镜像: `oceaneit/sso:latest`
- 端口: `9090`
- JWT 密钥路径: `/app/keys/private.pem`
